# 3x-ui 离线配置兼容性盘点

本工具用于落实 2026-09-30 确认的边界：配置不得丢字段，日常用户操作不得额外中断其他
连接，失败配置不得影响旧运行态。接受近似在线信息与原版计费缺口不放宽这些要求。

`agent/cmd/3xui-audit` 只从标准输入读取一份本地完整 Xray JSON，不连接节点或 3x-ui，
不打开数据库，不执行 Xray，不修改配置，也不建立任何访问授权。尚不支持直接读取
`core/cmd/equivalence` 的证据包；该包包含订阅与多个节点记录，不得整包作为配置输入。

## 用法与结果

```bash
go build -o bin/chiral-3xui-audit ./agent/cmd/3xui-audit
bin/chiral-3xui-audit < /private/verification/node-config.json
```

路径是示例，输入应来自已经准备好的私有配置副本。本命令不获取生产数据；不得为运行
盘点而自行连接 Turin、读取在线数据库或调用可能引发维护的 3x-ui 配置接口。

输入限制为 4 MiB、64 层 JSON 容器。拒绝重复键、无效 UTF-8／Unicode 转义、多个文档、
非对象根以及无法安全遍历的入站／用户集合。不接受命令行参数，避免参数诊断回显凭证。
结果仅包含固定原因代码、零起始入站／用户数组位置与计数，不包含 Tag、Email、凭证、
未知字段名或字段值。最多列出 64 项发现；达到上限后仍完成结构检查与用户计数，并标记
`truncated`。入站级发现使用 `client_index=-1`；其他位置均为零起始数组索引。
数组位置与数量仍属于运维信息，不应向订阅者公开。

| assessment | 含义 |
| --- | --- |
| `known_path_incompatibility` | 检出了在已审查应用路径中已知的字段保真问题；不代表所有官方 HTTP 路径均不可行 |
| `additional_review_required` | 包含尚未纳入本工具审查范围的用户字段、形状或协议，不能直接判定其不受支持 |
| `runtime_validation_required` | 没有发现本工具覆盖的问题；仍缺运行时与安全变更验证，不等于兼容通过 |

所有有效结果始终包含 `takeover_permitted=false` 和 `runtime_validation_required=true`。
`unverified_guarantees` 始终列出完整配置保真、日常用户变更连接连续性，以及失败配置保留
旧运行态这三项尚需验证的保证，不会因字段盘点没有发现问题而删除。
退出码 `2` 表示盘点已输出但**未批准接管**，无已知发现时也返回 `2`；退出码 `1` 表示
输入或读写失败且未完成盘点。本工具没有表示迁移验收通过的退出码 `0`，不能作为自动
切换 provider 的批准器。

## 当前覆盖范围

规则依据官方提交 `7ef22f94c950ff09f0870e2295fa65ad5968742c` 的 typed client、
`AddUser` 和热差分路径；`review_source` 是审计依据，不是固定部署版本或版本兼容白名单。
升级上游后须重新核对规则与运行实验，不能从版本字符串推导兼容。

- 检查入站 Tag 的非空唯一性，以及 `inbounds[].settings.clients[]`。当前具体字段审查覆盖
  VLESS、VMess 和 Trojan；Shadowsocks 和 Hysteria 也检查受管路径的 Level 丢失。
- 显式 `level` 会在受管 client 路径丢失；即使为 `0` 也不能以默认值相同为由认定字段保真。
  正整数非零 `level` 还标记原始模板的用户热添加路径风险。其他数值表示和类型交由进一步
  审查，不由盘点器模拟 Xray 的数值解析。
- 对 VLESS、VMess 和 Trojan 检查用户数组存在、Email 非空且在同入站内唯一。这些条件
  不满足时，官方不能使用仅更新用户的热差分路径，可能转为重建入站或重启。
- 非 `null` 的 `reverse` 用户配置会使官方对该入站的后续变更走完整重启，单独标记为
  已知风险。此处描述变更路径，不表示读取或保留不变的配置会重启服务。
- 已识别的基本凭证字段只表示本工具没有额外发现，不证明凭证合法或上游一定无损保留。
  未识别字段与协议报告“需审查”，绝不删除、归一化或输出其内容。

本工具不比较变更前后两份配置，也不完整检查传输、路由、DNS、出站、入站重建和用户
删除／停用／更新的执行路径；
也不证明旧连接持续可用、错误配置无副作用、配置已在运行态生效、计费可靠投递或订阅
等价。完整原始模板能够保存某字段，也不能抵消热应用路径的运行态问题。

后续须在隔离环境验证具体配置及变更路径。不兼容或尚未证明安全的节点保留 direct-Xray；
仅凭本盘点结果不得改变生产 provider，也不得静默改字段、重启或重建入站来取得通过。

## 本轮验证范围

2026-09-30 使用合成配置验证了已知 Level、反向代理及热差分前提风险，未知字段与协议、敏感信息不回显、输入
不被改写、重复键及错误形状拒绝、结果数量上限和明确不批准接管。全量 Go 测试、该包及
CLI 的竞态测试、`go vet ./...` 与 `go build ./...` 均有成功退出结果。首轮测试受本地
回环监听／构建缓存权限限制，授权后重跑通过；全部 3x-ui 实例测试入口显式关闭。

未取得适用的静态生产配置备份，未读取本地活动数据库，也未连接 Turin。本工具交付与
合成测试通过不代表真实节点语料已完成盘点，近似在线展示和生产写入路径也尚未接线。
